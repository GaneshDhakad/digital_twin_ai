FREQUENTLY ASKED QUESTIONS

Everything You Need to Know.

Answers regarding our software architecture, database security, and machine learning models.

TWIN.OS uses a 9-category simulation engine that takes your synchronized baseline state (from PostgreSQL) and projects it forward across 5 scenarios: Current Path, Best Case (95th percentile), Expected Path, Worst Case (5th percentile), and Risk Assessment. It checks your emergency fund buffer and target goal deadlines in real time.

Our Champion/Challenger Model Selector evaluates Prophet, ARIMA, XGBoost, and LightGBM for financial forecasting. For study and habit prediction, it compares Random Forest, XGBoost, and CatBoost. The model with the lowest Root Mean Square Error (RMSE) is automatically elevated to Champion status.

Yes. Every API route is protected by JWT authentication with bcrypt password hashing (`passlib`). Data is stored in a normalized PostgreSQL 15 database where every table is strictly scoped by `user_id` with foreign key constraints, preventing any cross-user data leakage.

Simply clone the GitHub repository and run `docker compose up` for full containerized deployment, or start the FastAPI server (`uvicorn main:app --port 8000`) and the Streamlit frontend (`streamlit run frontend/app.py`). Visit `http://localhost:8501/` to access the interface.
