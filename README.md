# Digital Twin AI

## Overview

Digital Twin AI is an AI-powered platform that creates a digital representation of a user to predict future outcomes related to finance, studies, habits, health, productivity, and goals using machine learning and simulations.

---

## Tech Stack

### Backend
- FastAPI
- SQLAlchemy
- PostgreSQL
- Redis

### Frontend
- Streamlit
- Plotly

### Machine Learning
- Scikit-learn
- XGBoost
- Prophet

### DevOps
- Docker
- Git
- GitHub Actions

---

## Running the Backend

```bash
uvicorn backend.main:app --reload
```

Open:

- http://127.0.0.1:8000/
- http://127.0.0.1:8000/docs
